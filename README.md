## 为什么做这个

「教-学-评」一体化是 2022 版课标的明确导向，但一线教学中有三重现实断裂：

1. **理念与设计断裂** —— 教师认可逆向设计（UbD）理念，却没有顺手的目标编写工具；
2. **教学与评价断裂** —— 备了课却难同步设计出与目标对齐的作业与量规；
3. **评价与改进断裂** —— 测了之后缺错因诊断，难以反哺下一轮教学。

NexEdu 把这三环做成**一条全自动链路**：教师只说需求，多智能体专家矩阵自动完成目标设计 → 教学设计 → 评价设计，且全程可解释、可中断、可修订。

**本地优先**：无需服务器，数据不出本机；支持云端模型（智谱 GLM 等）与本地模型（Ollama / LM Studio）双轨，后者可完全离线运行。

## ✨ 核心能力

| 能力 | 说明 |
| --- | --- |
| **一键备课** | 填课题即自动执行完整工作流：目标 → 教学设计 → 评价设计，产出节点卡片与 Word / PPT 工件 |
| **多智能体专家矩阵** | 42 位内置专家（目标 / 教学 / 评价 / 协调四环），按教学需求语义自动路由 |
| **内置技能库** | 177 条领域技能 + 通用技能（16 组），专家在需要时自动调用，无需手动编排 |
| **快速对话** | 6 路并行对话，历史会话可随时回看续问 |
| **本地知识库** | 上传教材 / 课件 / 课标，检索增强生成（RAG），内置种子语料 |
| **修订自检** | 产出自检最多 6 轮；中止时把剩余不足列清单交教师裁定 |
| **多模型支持** | 智谱 GLM / DeepSeek / Qwen / Kimi / OpenAI / 硅基流动 / Ollama / LM Studio |
| **导出** | 一键导出 Word 教案与 PPT 课件 |

## 🚀 快速开始

### 环境要求

- Windows 10/11（桌面壳基于 WinForms，其他平台自动降级浏览器窗口）
- Python 3.10+

### 运行

```bash
git clone https://github.com/<你的用户名>/nexedu.git
cd nexedu

# 核心功能零依赖（全部标准库实现），可选增强：
pip install -r requirements.txt

# 启动
py main.py
```

首次启动自动打开窗口。**不配置 API Key 也能用**——进入演示模式体验完整交互；在「设置」中填入任意兼容 OpenAI 协议的 Key 后即为真实调用。

### 接入模型

| 方式 | 说明 |
| --- | --- |
| 云端 | 智谱 GLM（推荐，`glm-4-flash` 免费）、DeepSeek、Qwen、Kimi、OpenAI、硅基流动 |
| 本地 | Ollama（`ollama pull qwen3` 后在设置中选择）、LM Studio（开启 Local Server） |

> API Key 只存在你自己的电脑上（`%APPDATA%/NexEdu/credentials.json`），**本仓库源码不包含任何密钥**，密钥文件也不会随源码 / exe 分发。

## 🔒 隐私与安全设计

- **数据不出本机**：会话、教案、知识库、日志全部落本地沙盒 `workspace/`；
- **密钥不进源码**：运行时才从用户目录读取，仓库自带 `tools/scan_secrets.py` 扫描闸门；
- **密钥不进打包产物**：打包脚本不会把 `credentials.json` 打进 exe；
- **默认不联网**：无云端依赖即可运行（本地模型模式）。
